# Plan: trip notes app

## Requirements

1. Every note can be written and saved with no network connection.
2. Notes appear on the second device within a minute of reconnecting.
3. Photos keep their original files; previews are made on the device.
4. Each save sends the note to the server and waits for its reply before the note is stored.

## Steps

1. Local database and capture screen.
2. Sync on reconnect.
