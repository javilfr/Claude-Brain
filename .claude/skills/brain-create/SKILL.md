# Create

Creative quality comes from real alternatives chosen well, not from asking for "creative" output; left alone, a model converges on its defaults. The outcome is one strong direction, built fully, or a short menu the owner picks from.

## 1. Brief

In about 150 words: the audience, the one job or feeling the piece must achieve, hard constraints from the ledger, and the named defaults to avoid for this medium. Name them specifically (for a screen: system fonts, purple gradients on white, pill buttons everywhere, "01/02/03" labels; for prose: stock openers, rule-of-three padding, a closing summary that restates the body). "Avoid a generic look" only swaps one default for another. `BRAIN recall "<medium> defaults to avoid"` returns any defaults learned so far.

## 2. Diverge

In one call, write five sketches of about 40 words each, each built on a different starting constraint: a different reference world, a different structural rule, a different stance toward the audience. Vary the constraint, not the adjectives. Include at least two you judge unusual.

## 3. Choose

Score the sketches against the brief without favouring your first idea (for a blind pick, give the sketches and the brief to a fresh scout): fits the brief, avoids the named defaults, distinct from the obvious answer, feasible. Pick one, optionally grafting one named element from the runner-up, and expand only that one.

## When taste decides, the owner chooses

For icons, names, palettes and layouts he wants a numbered menu, usually five, each an image with a one-line description. Show them as images he can open on his phone, kept out of git history: a published page or preview deploy if the session offers one, otherwise one downscaled set on a separate branch, linked in chat. Apply his choice everywhere it is used.

## Facts stay fixed

The creative pass changes form, framing, structure and visual language. It never changes facts, numbers, dates, names or legal content; those come from the facts file and sources.

## Tell the owner

The numbered options, or the chosen direction in two lines and where to see it.
