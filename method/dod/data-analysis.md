# Definition of done: Data analysis

Read before delivering an analysis, a table or a chart.

- [ ] Does one script reproduce every number and chart from the raw input, and was it re-run clean?
- [ ] Were input checks run: row counts, date ranges, duplicates, missing values, units?
- [ ] Do totals and headline numbers reconcile with an independent figure or a second computation?
- [ ] Were the charts rendered and looked at, with correct axes, units, baselines and labels?
- [ ] Do the claims stay within what the data supports, with sample sizes shown?
- [ ] Are the method, exclusions and limits written down?
