# Definition of done: Answer

Read before sending an answer to a question (size 0).

- [ ] Does the first sentence answer the question asked?
- [ ] Was anything checkable actually checked (file read, command run, source fetched) rather than recalled?
- [ ] Do facts about versions, prices, limits and APIs come from a current source?
- [ ] Is uncertainty stated once, plainly?
- [ ] If the question implies a decision, is a recommendation given?
- [ ] Is it in the language the owner wrote in, and short enough to read on a phone?
